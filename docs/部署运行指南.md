## 1. 环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Linux（CentOS 7+ / RHEL 7+ / Ubuntu 18.04+） |
| Docker | 已安装并运行（`docker info` 正常） |
| expect | `yum install -y expect` 或 `apt-get install -y expect` |
| 磁盘空间 | ≥ 20GB（三个镜像约 5-10GB） |
| 网络 | 宿主机有可用 IP，容器间可互通 |

## 2. 文件清单

部署前请确认以下文件齐全：

```
/opt/fix-test/scripts/
├── common.sh                 # 公共函数库（日志、IP 检测、Docker 辅助）
├── env_setup.sh              # ★ 主编排脚本（一键部署入口）
├── setup_exchange.sh         # 交易所容器搭建
├── setup_ctptrade.sh         # CTP 交易柜台容器搭建
├── setup_fixgateway.sh       # FIX 网关容器搭建
├── cleanup.sh                # 环境清理
├── exchangeFIX.tar           # Docker 镜像：交易所
├── CtpTradeFIX.tar           # Docker 镜像：CTP 交易柜台
└── FIX.tar                   # Docker 镜像：FIX 网关
```

## 3. 快速开始

```bash
# Step 1: 上传文件到 Docker 宿主机
scp -r scripts/ root@<宿主机IP>:/opt/fix-test/

# Step 2: 登录宿主机
ssh root@<宿主机IP>

# Step 3: 进入目录
cd /opt/fix-test/scripts

# Step 4: 一键部署
bash env_setup.sh

# Step 5: 验证
docker ps | grep -E 'exchangefix|ctptradefix|ctpfix'

# Step 6: 运行测试（在 FixAutoTest 机器上）
cd FixAutoTest/FixAutoTest
python FixInitiator.py
```

## 4. 分步详解

### 4.1 上传文件

将 `scripts/` 整个目录及三个 `.tar` 镜像文件复制到 Docker 宿主机：

```bash
# 在本地执行
cd /path/to/FixDockerAutoTest
scp -r scripts/ root@192.168.1.100:/opt/fix-test/
scp exchangeFIX.tar CtpTradeFIX.tar FIX.tar root@192.168.1.100:/opt/fix-test/scripts/
```

### 4.2 检查前置条件

```bash
# 确认 Docker 运行
docker info

# 确认 expect 已安装
which expect

# 确认 tar 文件存在
ls -lh /opt/fix-test/scripts/*.tar

# 确认脚本可执行
ls -l /opt/fix-test/scripts/*.sh
```

### 4.3 执行部署

```bash
cd /opt/fix-test/scripts
bash env_setup.sh
```

部署过程分为 3 个阶段，预计耗时 5-15 分钟：

```
阶段 1/3：交易所容器
  ├── 导入镜像 exchangeFIX.tar → exchangefix:v1
  ├── 创建容器 exchangefix（端口 26171, 26181）
  ├── 配置 SSH 密钥
  ├── setcap ping 权限
  ├── 修改 service.list（IP → 容器自身 IP）
  ├── 修改 DeployConfig.xml（IP + 组播地址）
  └── 启动交易所服务（ecall.sh → confirmMainBackup.sh）

阶段 2/3：CTP 交易柜台容器
  ├── 导入镜像 CtpTradeFIX.tar → ctptradefix:v2
  ├── 创建容器 ctptradefix（端口 11157, 11167, 11155）
  ├── 配置 SSH 密钥
  ├── 修改 /etc/hosts（添加 30+ 主机别名）
  ├── 修改 4 个 INI 文件 + GenMD5.sh
  │   ├── ineoffer.ini    (ExchangeAddress → 交易所IP)
  │   ├── inemdserver.ini (FrontAddr → 交易所IP)
  │   ├── shfeoffer.ini   (ExchangeAddress → 交易所IP)
  │   └── shfemdserver.ini(FrontAddr → 交易所IP)
  ├── 修改 DeployConfig.xml（组播地址）+ cpall.sh
  └── 启动 CTP 服务（startall.sh）

阶段 3/3：FIX 网关容器
  ├── 导入镜像 FIX.tar → ctpfix:v1
  ├── 创建容器 ctpfix（端口 50001, 61111）
  ├── setcap ping 权限
  ├── 修改 fixfront_mt.ini (CTPfront1 → CTP容器IP) + GenMD5.sh
  ├── 修改 fixfront_md.ini (MDfront1 → CTP容器IP) + GenMD5.sh
  └── 启动 FIX 网关服务（startall.sh）
```

### 4.4 验证部署

```bash
# 检查三个容器都在运行
docker ps --format 'table {{.Names}}\t{{.Status}}\t{{.Ports}}'

# 预期输出：
# NAMES         STATUS          PORTS
# ctpfix        Up XX minutes   0.0.0.0:50001->50001/tcp, 0.0.0.0:61111->61111/tcp
# ctptradefix   Up XX minutes   0.0.0.0:11155->11155/tcp, 0.0.0.0:11157->11157/tcp, 0.0.0.0:11167->11167/tcp
# exchangefix   Up XX minutes   0.0.0.0:26171->26171/tcp, 0.0.0.0:26181->26181/tcp

# 检查 FIX 端口可达
nc -zv localhost 61111
# 预期：Connection to localhost 61111 port [tcp/*] succeeded!
```

### 4.5 查看容器 IP

部署完成后脚本会打印各容器 IP。也可手动查询：

```bash
docker inspect -f '{{.Name}} → {{range .NetworkSettings.Networks}}{{.IPAddress}}{{end}}' \
    exchangefix ctptradefix ctpfix
```

## 5. 脚本说明

### 5.1 `common.sh` — 公共函数库

被所有脚本引用（`source`），提供：

| 函数/变量 | 说明 |
|-----------|------|
| `detect_host_ip()` | 自动检测宿主机 IP |
| `get_container_ip(name)` | 获取容器在 Docker 网络上的 IP |
| `get_broadcast_ip(ip)` | 基于 IP 计算 /24 子网广播地址 |
| `container_exists(name)` | 判断容器是否存在 |
| `image_exists(name)` | 判断镜像是否存在 |
| `network_exists(name)` | 判断 Docker 网络是否存在 |
| `log_info/error/success/step` | 带时间戳和颜色的日志输出 |

### 5.2 `env_setup.sh` — 主编排器

**用法：**
```bash
bash env_setup.sh
```

**功能：**
- 检查前置条件（Docker、expect、tar 文件）
- 创建 Docker 桥接网络 `fix-test-net`
- 按顺序调用三个阶段脚本
- 每个阶段完成后获取容器 IP 传递给下一阶段
- 打印部署摘要

### 5.3 `setup_exchange.sh` — 交易所容器

**镜像：** `exchangeFIX.tar` → `exchangefix:v1`
**容器：** `exchangefix`，端口 26171/26181
**用户：** trade2
**修改的配置文件：**
- `/home/trade2/shell/console/service.list`
- `/home/trade2/cfg/config/DeployConfig.xml`

### 5.4 `setup_ctptrade.sh` — CTP 交易柜台

**镜像：** `CtpTradeFIX.tar` → `ctptradefix:v2`
**容器：** `ctptradefix`，端口 11157/11167/11155
**用户：** trade1
**修改的配置文件：**
- `/etc/hosts`
- `~/ineoffer2/bin/ineoffer.ini`
- `~/inemdserver2/bin/inemdserver.ini`
- `~/shfeoffer1/bin/shfeoffer.ini`
- `~/shfemdserver1/bin/shfemdserver.ini`
- `/home/trade1/cfg/config/DeployConfig.xml`

### 5.5 `setup_fixgateway.sh` — FIX 网关

**镜像：** `FIX.tar` → `ctpfix:v1`
**容器：** `ctpfix`，端口 50001/61111
**用户：** fixf1
**修改的配置文件：**
- `/home/fixf1/fixfront_mt1/bin/fixfront_mt.ini`
- `/home/fixf1/fixfront_md1/bin/fixfront_md.ini`

### 5.6 `cleanup.sh` — 环境清理

**用法：**
```bash
bash cleanup.sh           # 仅清理容器和网络
bash cleanup.sh --images  # 同时删除 Docker 镜像
```

**清理顺序：** ctpfix → ctptradefix → exchangefix（逆依赖顺序）

## 7. 故障排查

### 7.1 容器启动失败

```bash
# 查看容器日志
docker logs exchangefix
docker logs ctptradefix
docker logs ctpfix

# 检查镜像是否存在
docker images | grep -E 'exchangefix|ctptradefix|ctpfix'
```

### 7.2 SSH 服务未启动

如果 `docker exec` 进入容器失败，说明 sshd 未正常运行：

```bash
# 手动启动（如果容器在运行但 sshd 挂了）
docker exec exchangefix /usr/sbin/sshd -D &
```

### 7.3 容器间网络不通

```bash
# 验证容器在同一网络
docker network inspect fix-test-net

# 从 FIX 网关 ping CTP 容器
docker exec ctpfix ping -c 3 $(docker inspect -f '{{range .NetworkSettings.Networks}}{{.IPAddress}}{{end}}' ctptradefix)
```

### 7.4 端口被占用

```bash
# 检查端口占用
ss -tlnp | grep -E '61111|50001|11157|11167|11155|26171|26181'

# 如果端口被占用，修改 docker run 的端口映射
# 编辑对应 setup_*.sh 中的 -p 参数
```

### 7.5 幂等性——重新部署

所有脚本支持重复执行（幂等）。如果需要完全重新部署：

```bash
# 方式 1：清理后重新部署
bash cleanup.sh --images
bash env_setup.sh

# 方式 2：直接重新运行（脚本会跳过已存在的步骤）
bash env_setup.sh
```

### 7.6 setcap 失败

如果看到 `setcap may have failed` 警告，这通常不影响核心功能（仅影响容器内 ping 命令）。如果需要修复：

```bash
# 在宿主机上给容器特权
docker exec --privileged exchangefix setcap cap_net_raw+ep /usr/bin/ping
```

### 7.7 GenMD5.sh 执行失败

检查 INI 文件路径是否正确：

```bash
# 在 CTP 容器内验证
docker exec ctptradefix ls -la /home/trade1/ineoffer2/bin/ineoffer.ini
docker exec ctptradefix ls -la /home/trade1/inemdserver2/bin/inemdserver.ini
docker exec ctptradefix ls -la /home/trade1/shfeoffer1/bin/shfeoffer.ini
docker exec ctptradefix ls -la /home/trade1/shfemdserver1/bin/shfemdserver.ini

# 在 FIX 容器内验证
docker exec ctpfix ls -la /home/fixf1/fixfront_mt1/bin/fixfront_mt.ini
docker exec ctpfix ls -la /home/fixf1/fixfront_md1/bin/fixfront_md.ini
```

### 7.8 startall.sh 或 ecall.sh 未找到

这些脚本应该在对应用户的 PATH 中。如果找不到：

```bash
# 尝试使用完整路径
docker exec exchangefix su - trade2 -c "which ecall.sh"
docker exec ctptradefix su - trade1 -c "which startall.sh"
docker exec ctpfix su - fixf1 -c "which startall.sh"
```

## 8. 常用命令

```bash
# 查看所有容器状态
docker ps -a --format 'table {{.Names}}\t{{.Status}}\t{{.Ports}}'

# 进入容器
docker exec -it exchangefix bash
docker exec -it ctptradefix bash
docker exec -it ctpfix bash

# 查看容器内某文件
docker exec exchangefix cat /home/trade2/shell/console/service.list
docker exec ctptradefix cat /home/trade1/ineoffer2/bin/ineoffer.ini
docker exec ctpfix cat /home/fixf1/fixfront_mt1/bin/fixfront_mt.ini

# 查看容器 IP
docker inspect -f '{{.Name}}: {{range .NetworkSettings.Networks}}{{.IPAddress}}{{end}}' exchangefix ctptradefix ctpfix

# 重启某个容器
docker restart exchangefix
docker restart ctptradefix
docker restart ctpfix

# 查看容器资源使用
docker stats --no-stream exchangefix ctptradefix ctpfix

# 导出容器日志
docker logs exchangefix > exchange.log 2>&1
docker logs ctptradefix > ctptrade.log 2>&1
docker logs ctpfix > fixgateway.log 2>&1
```
